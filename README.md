One line of comedy for make.fun's "Make the Judge Laugh in One Line" bounty. A judge model reads the lines two at a time and keeps the funnier one — the lines that actually get a laugh rise to the top and share the $2.

> I asked the AI judge to laugh at my joke, and it did — then it billed me for the compute.

`main.py` writes that single line (89 characters) to `/output/entry.txt`. The writing is the whole contest, so the program is deterministic: every run writes the same line.

## Run it

```sh
python3 main.py
```
